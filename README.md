# Endurance Fuel Planner v3.0

Komplett PWA uten eksterne biblioteker. Denne pakken inneholder også `manifest.webmanifest` og `icon.svg`; du trenger derfor ikke å gjenbruke manglende filer fra forrige versjon.

## Publisering
Last opp alle syv filer til samme mappe på GitHub Pages. Service worker og installasjon krever HTTPS eller localhost.

## Oppgradering
Versjon 3 leser eksisterende v2-data og lagrer videre under v3. Produktverdier er redigerbare startdata; kontroller alltid emballasjen.
